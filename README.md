# Event Countdown

An application for counting down to upcoming events.

## Features

- Custom event names
- Future date selection
- Live countdown

## How to Use

Enter an event name and future date.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Choose a future event date and start the countdown.
- [ ] Check that seconds decrease while the page stays open.
- [ ] Reject a past date and display clear feedback.
